# AI-Based Mental Health Prediction and Support System

A lightweight Flask application that predicts mental wellness risk for students using a trained Random Forest model, provides friendly chatbot support, and serves actionable recommendations.

## Features
- Predict mental wellness risk using user inputs (academic pressure, sleep, financial stress, etc.)
- Friendly rule-enhanced ML predictions with human-readable suggestions
- Simple conversational chatbot for supportive responses
- Model training script included (`train_model.py`)

## Project Structure

- `app.py` — Flask web application and routes (`/`, `/predict`, `/chatbot`, `/recommendation`).
- `train_model.py` — Script to train the Random Forest model and save `model.pkl`.
- `requirements.txt` — Python dependencies.
- `dataset/mental_health.csv` — CSV used to train the model (not tracked here if large).
- `templates/` — HTML templates used by Flask.
- `static/` — CSS and other static assets.
- `model.pkl` — Trained model file (generated by `train_model.py`).

## Quickstart (local)

1. Create and activate a virtual environment (recommended):

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. If you don't have a trained model, train one (this will create `model.pkl`):

```powershell
python train_model.py
```

4. Run the Flask app:

```powershell
python app.py
```

5. Open your browser at `http://127.0.0.1:5000/`.

## Notes on Training
- `train_model.py` reads `dataset/mental_health.csv`, preprocesses data, trains a Random Forest classifier, prints evaluation metrics, and saves `model.pkl`.
- Ensure the CSV columns match the expected features used in `train_model.py` and `app.py`.

## Deployment
- A `Procfile` is present for simple Heroku-style deployments; ensure `model.pkl` is present or produced during build.
- Use a production WSGI server (the repo includes `gunicorn` in `requirements.txt`).

## Security & Privacy
- This project processes sensitive mental health-related inputs. Do not expose identifiable or private user data in public deployments.
- Add TLS/HTTPS, authentication, and clear privacy notices before any production use.
